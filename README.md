# Peekabond

A family-oriented social media app built by a 6-person Scrum team, 
delivering a functional MVP in one month.

> This repo is my personal fork from the team project.

## About

Peekabond is a mobile app designed to help families stay connected 
through shared moments. I joined the team as a React Native developer 
and contributed to 3 core user journeys, including a Snapchat-style 
video overlay feature.

## My Contributions

- Built 3 key user journeys in React Native and Expo
- Developed a Snapchat-style video overlay feature
- Worked within a Scrum workflow with daily standups, 
  sprint planning, and code reviews

## Tech Stack

- React Native
- Expo
- GraphQL (Apollo)
- Scrum / Agile

## Team

Built as part of a 6-person development team.
